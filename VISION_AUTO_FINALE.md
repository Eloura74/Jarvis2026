## 🔧 **COMMENT ÇA MARCHE**

### **Technologie Utilisée**
- **html2canvas** : Bibliothèque spécialisée pour capturer le DOM
- **Gemini 2.5 Flash Vision** : Analyse de l'image
- **Synthèse vocale** : Lecture du résultat

### **Ce qui est Capturé**
- ✅ Toute l'interface J.A.R.V.I.S. visible
- ✅ Widgets (Météo, Réseau, etc.)
- ✅ Neural Feed
- ✅ Boutons, textes, animations
- ✅ Couleurs, design, layout

### **Ce qui N'est PAS Capturé**
- ❌ Autres fenêtres (VSCode, Chrome, etc.)
- ❌ Le bureau Windows
- ❌ Applications externes

**Pourquoi ?** Sécurité du navigateur. Seul l'onglet actif peut être capturé sans permission.

## 📊 **TYPES D'ANALYSE DISPONIBLES**

### **1. Analyse Générale** (par défaut)
```
"Analyse l'écran"
"Qu'est-ce que je vois ?"
"Décris l'interface"
```
→ Description complète de ce qui est visible

### **2. OCR - Lecture de Texte**
```
"Lis le texte sur l'écran"
"Lis les logs"
"Extrais le texte"
```
→ Extraction de tout le texte visible

### **3. Détection d'Erreurs**
```
"Trouve les erreurs"
"Y a-t-il des bugs ?"
"Cherche les problèmes"
```
→ Recherche de messages d'erreur, bugs

### **4. Analyse d'Interface**
```
"Analyse le design"
"Décris l'UI"
"Comment est l'interface ?"
```
→ Analyse UX/UI, couleurs, disposition

### **5. Analyse de Code** (si code visible)
```
"Analyse ce code"
"Revue de code"
```
→ Suggestions, améliorations
