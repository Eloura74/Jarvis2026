# 🎉 NOUVELLES FONCTIONNALITÉS J.A.R.V.I.S.

## ✅ CE QUI A ÉTÉ AJOUTÉ

### 1️⃣ **Raccourcis Clavier Globaux** ⌨️

**Raccourci activé** : `Ctrl + Space`

**Comment ça marche** :
- Appuyez sur `Ctrl + Space` **n'importe où dans l'application**
- J.A.R.V.I.S. commence l'écoute vocale immédiatement
- Fonctionne même si vous êtes dans un autre onglet !

**Où configurer** :
- Bouton "CONFIG APPS" → Onglet "Raccourcis"
- Vous pouvez activer/désactiver les raccourcis
- (Personnalisation complète à venir)

---

### 2️⃣ **Panneau de Configuration Unifié** ⚙️

**Où** : Bouton "CONFIG APPS" (colonne droite)

**3 onglets disponibles** :

#### 📁 **Applications**
- Gérer les chemins des applications
- Ajouter de nouvelles applications
- Modifier/Supprimer les chemins existants

#### ⌨️ **Raccourcis**
- `Ctrl + Space` : Activer l'écoute (activé par défaut)
- `Ctrl + Shift + J` : Ouvrir/Fermer J.A.R.V.I.S. (à venir)
- `Ctrl + Alt + S` : Capturer et analyser l'écran (à venir)

#### ⚡ **Commandes Personnalisées**
- Créer des macros (séquences d'actions)
- Exemples prédéfinis :
  - **"Mode Travail"** = Lance VSCode + Chrome + Spotify
  - **"Pause Café"** = Lance Spotify + Ouvre YouTube
